> ## ⚠ 2026-09-30 更正：下面用英文判準量的數字，是拿一個壞掉的英文包量的
>
> 有兩個 bug，一個讓英文的建卡結果偏一點，一個讓英文的 KP 檢查明顯偏嚴：
>
> 1. **定義句被截斷。** `en.yaml` 的技能列用行內 `{...}` 寫法，`meaning:` 的英文值含逗號卻沒加引號，
>    YAML 把第一個逗號當欄位分隔，定義句只剩第一個詞（`Computer Use: "operating computers"`、
>    `Locksmith: "opening"`、`Language (Other): "reading"`），**24 項技能**，而且不報錯。
>    日文用「・」分隔，中文用全形標點，都沒中招。
> 2. **技能名稱比對會送錯定義。** 比對時先砍括號再模糊取第一個，`Language (Own)` 與
>    `Language (Other)` 砍完都是 `language`，誰贏看字典順序：Python 讀 YAML 順序（母語先）、
>    Worker 讀排序過的 `system.js`（外語先），**剛好相反**，Worker 會把兩個都送成「非母語」的定義。
>    這就是英文 KP 頁「Language (Own) 80 誤判撐不起（背景只撐得起 39）」的來源。
>
> 修法：定義句加引號；載入語系檔時技能條目只准有 `label/meaning/evidence/family/aliases`，
> 多出鍵直接 exit（閘）；比對改成「全名含括號 → 去限定詞 → 子字串唯一命中，有歧義就不猜」，
> Python 與 JS 同一套，並用 Python 算答案的固定樣本讓 `test.mjs` 對（32 項）。
>

## 讀法

**一、卡的形狀跨語言是穩的。** 等級相關 0.94–0.97、前八名重疊 6.5–7 項，**職業四臂一模一樣**
（1920 工程師、現代顧問），學歷全是 75。三語都可以上。

**二、但判準的語言本身會移動數字，影響約是履歷語言的兩倍。**〔已更正：修復後英文 1.4 倍、日文 2.1 倍，見上〕 把兩者拆開：

| | 判準語言的影響（同一份中文履歷，只換題目） | 履歷語言的影響（同一套判準，只換履歷） |
|---|---|---|
| 英文 | \|B − A\| = **3.3** 分／項 | \|C − B\| = 1.7 分／項 |
| 日文 | \|E − A\| = **4.4** 分／項 | \|D − E\| = 2.2 分／項 |

**三、個別技能可以擺 20–35 分，而且幾乎全部來自判準語言：**〔英文那欄是壞掉的包造成的，日文那欄有效；見上〕

| 技能 | A 繁中 | 英文判準造成 | 日文判準造成 |
|---|---|---|---|
| 信用評級 | 38 | +2 | **+34** |
| 領導 | 48 | **+19** | +7 |
| 圖書館使用 | 54 | **−18** | +5 |
| 估價 | 49 | +7 | **−22** |
| 心理學 | 34 | +2 | +12 |

**四、我原本的假設大半錯了。**〔英文那一半的實驗也是拿壞掉的包做的，不成立；日文那一半有效〕 我先猜是「技能名翻過去意思變了」（日文「信用」一般指可信度、
英文 "Library Use" 字面感太強），只改標籤重跑：

- 日文 信用評級：「信用」→「信用（経済力）」，73 → **70**。幾乎沒動，**不是標籤的問題**。
- 英文 圖書館使用："Library Use" → "Library Use (Research)"，33 → **40–42**，救回約一半，
  但信心崩到 0.00–0.07，變成雙峰。

所以標籤語意只解釋了一小部分，其餘來自整套判準（定義句、證據句、題目措辭）在那個語言裡
被讀得不同。這是量出來的，我沒能把它再拆得更細。

**五、沒有標準答案，就不能說哪個語言比較對。** 我原本推測英文判準可能更準（因為 Jev 官方說英文最強），
這組數據**沒有支持也沒有推翻**：三語的平均信心幾乎一樣（0.746–0.763），而「更一致」不等於「更正確」。
例如領導：這份履歷有「主導千人培訓體系」與兼任技術長，英文的 67–73 看起來比中文的 48 合理；
但圖書館使用：有期刊論文與架構稽核，中文的 54、日文的 60 看起來比英文的 33 合理。
**沒有哪個語言整體比較好，是逐項不同。**

## 對產品的意思

- 三語都上。形狀穩、職業穩，這個東西在每個語言裡都說得通。
- 頁尾明寫：**不同語言做出來的卡，數字不要互比**。
- 想知道哪一套判得對，需要標準答案：找幾位 KP 或熟悉 d100 的人，對十幾份履歷標出他們覺得合理的
  技能值，再看哪個語言的判準比較接近。那是下一步，不是這一步。

## 限制

- 只有一份履歷。擺盪大的那幾項是不是對所有履歷都擺，不知道。
- 三個語言版本的履歷是我翻的，措辭不可能完全等價——但 B／E 臂用同一份中文履歷只換判準，
  把這個因素隔離掉了，判準語言的效果不受翻譯影響。
- 日文判準是機翻等級，未經母語者校對。
