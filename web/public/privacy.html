關於本站

JevTRPG 由編年史記工作室 ChronicleCore Studio 開發與維護，作者 Zaious。它把你貼上的履歷（或角色背景）交給 TypeSafe 的判斷模型 Jev 判讀，印成一張 d100 跑團風格的調查員檔案。這是以 Jev 為發想做出來的應用，是遊戲，不是能力評估。本站是非官方作品，與 TypeSafe、Chaosium 沒有合作關係，也不是任何遊戲的官方或相容產品。
問題回報或聯絡作者：jevtrpg@chroniclecore.com

這個網站怎麼維持免費

每一次判讀，本站都要付費呼叫 Jev API。網站免費給大家用，這些費用主要靠頁面上的廣告收入支付。為了避免被程式大量呼叫，單次內容有 12,000 字元的上限、每個 IP 每小時與全站每天各有使用次數上限（全站每天的計數在台北時間午夜重置），送出前也會用機器人驗證確認是真人。

你貼上的文字

  • 文字會送到 TypeSafe 的 Jev API 判讀，依 TypeSafe 自己的資料政策處理，所以內容會離開你的瀏覽器。
  • 履歷頁：送出之前，你的瀏覽器會先把信箱、電話、身分證字號、地址、生日、社群連結，以及你自己列出的字詞（例如姓名、公司、學校）換成標記，這些字不會離開你的電腦。伺服器收到後再用同一組規則遮一次。角色頁只有伺服器這一次。
  • 你可以把 PDF、.docx 或純文字檔拖進履歷頁。檔案只在你的瀏覽器裡讀成文字（PDF 用本站自己託管的 pdf.js），檔案本身不會上傳。
  • 遮蔽有限制：規則只認得有固定格式的東西。沒有標籤的地址、夾在句子裡的姓名、公司與學校名稱都抓不到，要自己列在「另外要遮掉的字詞」；掃描成圖片的 PDF 讀不出字。送出前請用「看遮完的樣子」確認。
  • 本站不儲存你的文字：它只在一次請求的記憶體裡走一趟，不寫進資料庫、檔案或日誌，判讀完就丟掉。
  • 不想送出去的段落，請先自己刪掉。
  • 為了限制使用次數，伺服器會把你的 IP 位址加鹽後轉成無法還原的雜湊值，只記「這一小時用了幾次」，不含任何內容，過了這一小時就清掉。
  • 卡片上的職業、數值與背景欄位是判讀結果，不含你貼上的原文。

分享連結

按「分享這張卡」並複製連結時，卡片的內容（職業、特性值、技能值與背景欄位）與你填的角色名字（選填）會被編碼在網址 # 後面的部分。這一段不會送到本站伺服器，所以本站不會知道有人分享過。但拿到連結的人看得到整張卡，請當作公開的東西。

機器人驗證

判讀前會用 Cloudflare Turnstile 確認是真人在使用，大多數時候你不會看到它。沒有通過驗證的話你仍然可以使用，只是每小時能用的次數比較少。Cloudflare 的隱私說明見 cloudflare.com/privacypolicy。

廣告

本站使用 Google AdSense 顯示廣告。Google 與其合作夥伴可能使用 Cookie，依你先前瀏覽的網站顯示廣告。你可以到 Google 廣告設定關閉個人化廣告，或參考 Google 如何使用合作網站的資料。

使用分析

本站用 PostHog 統計頁面瀏覽和功能使用次數（例如產生了幾張卡、用哪種介面語言、有沒有打開範例），不使用 Cookie、不跨次造訪追蹤同一個人，也不收集你貼上的文字和判讀內容。

贊助不會增加或解鎖任何功能，站上所有功能對所有人都一樣，這是純粹的支持，不是購買。

網站怎麼送到你眼前

本站託管在 Cloudflare。頁面的字型從 Google Fonts 載入，所以 Google 會收到你瀏覽器的 IP 位址與字型請求。

判讀結果

判讀由 AI 完成，可能出錯。同一份文件換不同語言的判準，證據含糊的技能可能差到 20 分（日文版最多量到 36 分），所以請不要拿不同語言做出來的卡互比。特性值裡履歷讀不出來的（體質、外貌、幸運等）是擲骰，種子來自文件內容，同一份文件會得到同一組。結果卡上的「重骰能力值」會換一組新的隨機值（不呼叫 Jev，技能與 EDU 不變）。
