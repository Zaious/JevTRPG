# 系統包：1920s／現代調查員（d100）

這個資料夾是一個**可替換的系統包**。`engine/` 不認識任何規則，規則全在
`system.yaml`：55 項技能（基礎值 ＋ 定義）、八項特性值與骰式、點數預算公式、
五級證據量表、兩套職業清單（1920／現代）、六張背景故事表。

## 授權與界線

- **技能名稱**（圖書館使用、話術、偵查……）是 d100 這一系遊戲的通用術語。
- **本檔裡所有的描述文字都是原創**：技能定義、證據量表的五個等級、職業清單的
  說明、背景故事表的條目，沒有一條是從任何出版品轉載的。
- **沒有收錄任何特定作品專有的內容**：沒有專屬的神話知識技能、沒有理智值規則、
  沒有任何出版品的職業表或劇本內容。
- 遊戲機制（d100 骰低、特性值、技能百分比）不受著作權保護。

**本專案與 Chaosium 無關，未受其委託或授權，也不是任何遊戲的官方或相容產品。**
「Call of Cthulhu」為其所有者之商標，此處未作為產品名稱使用。

如果你要把這個包拿去做公開服務，上線前自己再確認一次現行的粉絲創作政策。

## 怎麼改

- **加技能**：在 `skills:` 下加一列 `名稱: {base: 數字, meaning: 這項技能實際在測什麼}`。
  `meaning` 很重要——技能名稱是行話，不附定義模型會照字面讀。
- **標成文件讀不出來的**：加 `reachable: false`（體能、戰鬥類預設如此），
  這些技能平常不問，`--all` 才問。
- **改點數公式**：`budget:` 下只准用特性值名稱與四則運算。
- **換整套規則**：複製整個資料夾改名，`python cli.py --system <新名字> build ...`。
